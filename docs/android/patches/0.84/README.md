# СВАЛКЕР · Alfa 0.84

Релиз-кандидат, созданный на основе APK 0.82.

## Изменения

- Нижняя панель показателей и кнопка «Вылазка» прижаты к нижней части расширенной панорамы поселения.
- Добавлена затемнённая панель и плавный верхний градиент, чтобы интерфейс читался поверх фона.
- На стартовом экране справа внизу написано `Alfa 0.84`.
- Добавлен скрипт проверки обновлений с `versionCode=84`.

Файлы игры, инвентарь, баланс и игровая логика не менялись.

## Сборка Android

Имя APK: `SVALKER-Alfa-0.84.apk` (APK доставлен через чат; в GitHub Releases пока **не загружен**).
Пакет: `com.kashara.svalker`, `versionCode=84`, `versionName=0.84`.
Встроен `android.permission.INTERNET`. Подписан тем же сертификатом, что APK 0.82.

**Не обновлять** `docs/android/latest.js` до 84, пока соответствующий APK не прикреплён к действующему GitHub Release и не проверен на реальном телефоне. Иначе в установленном 0.83 появится ссылка на несуществующую загрузку.

Для дальнейших версий распространяем полный APK через GitHub Releases; это пока не система горячего обновления игровых файлов.
