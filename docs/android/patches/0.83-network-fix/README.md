# СВАЛКЕР 0.83 — исправленная проверка обновлений

Проблема оригинального APK 0.83: метод Android WebView `MainActivity.assetResponse` в `classes.dex` вместо передачи внешних HTTPS-запросов сетевому стеку возвращал `403 Forbidden`. Поэтому встроенный скрипт не мог получить `https://mikiawelloo.github.io/svalker-updates/android/latest.js`.

Исправление: для запросов вне собственного `appassets.androidplatform.net` вернуть `null` из `shouldInterceptRequest`/вспомогательного `assetResponse` (в нашей сборке исправлен `assetResponse`), чтобы штатный WebView сам загрузил HTTPS. Для локальных ресурсов сохранена существующая безопасная обработка.

Дополнительно скрипт `svalker-updater-v83.js` теперь выводит результат проверки и добавляет кнопку **«Проверить обновления»** в меню **Настройки**. Файлы игры и сохранения не менялись.

Сборка распространяется **вне GitHub Releases** как исправленная `0.83`, с прежним `versionCode=83`, тем же Android package name и сертификатом подписи. В результате её можно установить поверх установленной `0.83`, не удаляя приложение. После установки и доступа к сети на сервере уже доступна Alfa 0.84: игра должна предложить ссылку на [выпуск 0.84](https://github.com/mikiawelloo/svalker-updates/releases/tag/0.84).

Проверено локально: ZIP целый, подпись APK Signature Scheme v2 корректна, сертификат совпадает с 0.83 и 0.84, файл DEX имеет корректные SHA-1 и Adler32, изменены только `classes.dex` и `assets/www/svalker-updater-v83.js`.

**Не проверено на реальном Android**: фактическое соединение WebView с GitHub Pages, наличие уведомления и установка 0.84. Никакие ключи подписи или пароли в репозиторий не выкладывались.
