# СВАЛКЕР Alfa 0.85

Версия для тестирования перехода **0.84 → 0.85** через GitHub. На основе опубликованного APK 0.84.

Изменения:
- Исправлена блокировка внешних HTTPS-запросов в Android WebView, перенесено подтверждённо рабочее исправление из 0.83 Network Fixed.
- При следующем обновлении добавляются две ссылки: **Скачать APK** (прямая ссылка) и **Страница выпуска** (резервная).
- Отображаются список изменений и размер APK, если сервер передаёт поле `apkSizeBytes`.
- Ручная проверка обновлений из настроек с выводом статуса соединения.
- Надпись на стартовом экране `Alfa 0.85`.
- Сохранены фон и градиентный нижний HUD из 0.84.

Сборка:
- Пакет: `com.kashara.svalker`
- `versionCode=85`, `versionName=0.85`.
- Подписан тем же сертификатом, что 0.83/0.84, Android APK Signature Scheme v2 проверена.
- Проверены целостность ZIP, выравнивание хранимых файлов и неизменность остальных игровых ресурсов.
- Размер файла: **262940962 байта** (250,8 МиБ).
- SHA-256: `4d256da4de18970d8e60250492858d9bcbcca7a07ea27d7e9f2e05a5f3c7dd34`

**Статус:** APK подготовлен в ChatGPT и сохранён в библиотеку игры. Он **ещё не опубликован в GitHub Releases**. Пока не менять `docs/android/latest.js` с 0.84 на 0.85, чтобы установленная игра не предлагала несуществующий файл.

После публикации APK как GitHub Release обновить `docs/android/latest.js` до `versionCode:85`, указать `apkUrl` реального скачивания, `apkSizeBytes:262940962`, release notes и правильный URL страницы выпуска.

**Ограничение:** прямая загрузка APK внутри Android WebView ещё не проверена на телефоне и может потребовать доработки оболочки. Поэтому в 0.85 оставлена вторая кнопка для страницы выпуска. Установка APK всегда требует участия пользователя. Не выкладывайте ключ подписи и пароль в публичный GitHub.
