# СВАЛКЕР: канал Android-обновлений

Этот каталог содержит **только метаданные** обновлений Android-версии. Реальные APK публикуются в [GitHub Releases](https://github.com/mikiawelloo/svalker-updates/releases).

## Переход с 0.82 на 0.83

0.82 не имеет разрешения `android.permission.INTERNET` и встроенного обновлятора. Поэтому 0.83 с загрузчиком нужно **установить один раз вручную** поверх 0.82. Не удаляйте приложение перед обновлением.

0.83:
- имя пакета `com.kashara.svalker`, код версии `83`, версия `0.83`;
- подписана тем же ключом, что 0.82;
- при запуске подключает `android/latest.js` с GitHub Pages;
- при появлении более нового `versionCode` выводит ссылку на GitHub Releases;
- не выполняет тихую установку APK и не обновляет игровые файлы отдельно.

## При выпуске 0.84 и позднее

1. Подготовить новую APK с увеличенным `versionCode` и **тем же ключом подписи**.
2. Проверить установку поверх 0.83 и сохранение игрового прогресса.
3. Создать GitHub Release, приложить APK.
4. **Только после загрузки** исправить `docs/android/latest.js`: `version`, `versionCode`, `notes`. `releasePageUrl` ведёт на последний релиз.
5. Установленная 0.83 получит уведомление при следующем запуске с интернетом.

**Важно:** ссылки на выпуск могут открываться во встроенном WebView, а не системном браузере, поэтому необходим тест на реальном Android. Проверять в браузере на компьютере недостаточно.

Никаких ключей подписи, паролей и личных данных в публичном репозитории быть не должно.
