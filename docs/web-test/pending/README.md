# СВАЛКЕР — накопительный браузерный UI-патч (после Alfa 0.85)

Это **исходники и диффы будущего патча**, а не опубликованная версия игры или APK.

Изменения:
1. Отступ нижней панели 52 CSS-пикселя с учётом safe-area Android; интерфейс и кнопка «Вылазка» больше не накладываются на системные кнопки.
2. В **модальных окнах услуг** медика и учёного убраны изображения. Персонажи в игровых сценах остались.
3. Нижняя панель затемнена и снабжена градиентом как на базе, так и при нахождении внутри помещений/NPC.
4. Подписи построек на канвасе подняты; HTML-навигация и центральная подпись адаптированы для узких экранов.

База изменений: веб-содержимое `SVALKER-Alfa-0.85.apk`.
Рабочие файлы сохранены в приватной библиотеке проекта:
- `/Разработка игры/SVALKER-browser-test-next-patch.zip` — только четыре изменённых файла;
- `/Разработка игры/SVALKER-browser-test-full-next.zip` — полная браузерная копия с игровыми ресурсами.

Указанные здесь diff-файлы не содержат ресурсов и не загружаются игрой автоматически.
Сайт ChatGPT `svalker-test-lab.tastythyme32.chatgpt.site` **не изменён**: для редактирования этого отдельного нативного сайта в текущем подключении нет инструмента публикации.

Локальная проверка Chromium: игра запускается на ширине 393px; нижняя кнопка имеет отступ 52px от края; окна медика и учёного работают без портретов; в консоли JS-ошибок нет.

**Версия Android и `docs/android/latest.js` не изменены.** Не объявлять этот патч новым релизом, пока его не перенесут в исходники соответствующей сборки.
