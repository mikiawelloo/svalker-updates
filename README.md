# СВАЛКЕР: обновления тестовой игры

Стартовый публичный репозиторий для проверки новых версий **СВАЛКЕРА**.

Сейчас работает **проверка версии и уведомление о наличии обновления** в демонстрационной браузерной странице. Автоматическая замена игровых ресурсов и установка APK **ещё не реализованы**. Исходный код игры пока не подключён.

## Включение GitHub Pages

1. Открой **Settings → Pages**.
2. В **Build and deployment** выбери **Deploy from a branch**.
3. Укажи ветку **main**, папку **/docs** и нажми **Save**.
4. После публикации открой https://mikiawelloo.github.io/svalker-updates/

Файл версий будет здесь: https://mikiawelloo.github.io/svalker-updates/version.json

## Проверка уведомления

В демонстрационной странице текущая версия зафиксирована как `0.1.0`.
Измени поле `version` в `docs/version.json` на `0.1.1` и снова нажми **Проверить обновления**.

Внимание: это искусственная проверка обнаружения версии; **APK версии 0.1.1 ещё нет**.

## Будущая публикация APK

1. Собери новый APK с увеличенным Android `versionCode`.
2. Подпиши его **тем же ключом**, что и предыдущую сборку, и сохрани прежний application ID.
3. Создай GitHub Release, прикрепи файл `svalker.apk`.
4. В `docs/version.json` установи `version` и `apkUrl`, указывающий на реальный загруженный файл.
5. Подключи `docs/updater.js` к браузерному интерфейсу игры, а механизм скачивания и вызова системного Android-установщика разработай в оболочке APK.

Пример адреса файла *после создания Release*:
https://github.com/mikiawelloo/svalker-updates/releases/latest/download/svalker.apk

Android обычно требует подтверждения установки APK от пользователя.

## Подключение к игре

Для браузерной части можно использовать скрипт `docs/updater.js` и вызвать:

```html
<script src="updater.js"></script>
<script>
SvalkerUpdater.init({
  manifestUrl: 'https://mikiawelloo.github.io/svalker-updates/version.json',
  currentVersion: '0.1.0',
  root: document.body
});
</script>
```

Это только проверка и отображение ссылки. Для доставки изменённых HTML/JS/музыки без нового APK потребуется либо удалённое размещение игрового интерфейса, либо надёжный отдельный загрузчик ресурсов и проверка файлов. Сохранения должны храниться отдельно от обновляемого содержимого.

**Безопасность:** публичные репозиторий и Releases доступны всем. Не выкладывай в них ключи подписи, пароли или секреты.
